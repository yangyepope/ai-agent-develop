这一课真正需要你理解的是下面这些关系：

概念 你需要理解什么
LLM 提供语言推理/生成能力的模型
API 程序调用模型能力的接口
Model 具体使用哪个模型
Prompt 给模型的指令和上下文
Message LLM 对话中的基本消息单位
System 定义模型行为
User 用户输入
Assistant 模型输出
Temperature 控制输出随机性的重要参数
Max Tokens 输出长度限制
Token 模型处理文本的基本单位
Context Window 一次请求可处理的上下文范围
API Key API 身份认证
Streaming 流式获取模型输出
Chat History 应用程序维护的历史消息
JSON API 数据交换格式
