# 01 · 环境准备

系统：Debian 13 (trixie) / WSL2。环境已装好，本文只记录装了什么、怎么验证。

## 装好的版本

| 组件    | 版本                   | 位置                            |
| ------- | ---------------------- | ------------------------------- |
| nvm     | 0.40.3                 | `~/.nvm`                        |
| Node.js | v24.21.0 (LTS Krypton) | `~/.nvm/versions/node/v24.21.0` |
| npm     | 11.19.0                | 随 Node                         |

## ⚠️ WSL 的坑：Windows 的 Node 不算 Node

现象：`node -v` 报 command not found，但 `npm -v` 有输出。

原因：WSL 把 Windows 的 `PATH` 追加在后面，`/mnt/c/nvm4w/nodejs` 里的 `npm`
是 shell 脚本（能跑），`node` 是 `node.exe`（Linux 不认）。

所以**必须**确认这一条：

```bash
which node    # 要指向 ~/.nvm/...，不能是 /mnt/c/...
```

若指向 `/mnt/c/...`：`source ~/.bashrc` 或重开终端。

## 为什么用 nvm 而不是 apt

- `sudo` 需要密码，apt 装不了
- Debian 13 仓库里的 Node 是 20，太旧（本工程需要 24）
- nvm 装在 `~/.nvm`，纯用户级，还能随时切版本

## 安装步骤（已执行，仅作记录）

```bash
# 1. 装 nvm（先下载再执行，方便先看一眼脚本内容）
curl -fsSL -o install_nvm.sh https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh
bash install_nvm.sh
source ~/.bashrc

# 2. 装 Node
nvm install 24
```

安装脚本会往 `~/.bashrc` 末尾追加 nvm 加载代码。追加在**末尾**很关键 ——
保证 nvm 路径插在 `PATH` 最前面，盖住 Windows 那些路径。

## 版本锁定

| 文件                        | 内容                 | 作用                                 |
| --------------------------- | -------------------- | ------------------------------------ |
| `.nvmrc`                    | `24`                 | 在项目目录执行 `nvm use` 自动切到 24 |
| `package.json` 的 `engines` | `"node": ">=24.0.0"` | 声明低于 24 别跑                     |

## 代理

已配好环境变量（`http_proxy` / `https_proxy` / `all_proxy` 指向 `172.24.112.1:7891`），
npm 和 Node 的 `fetch` 都会自动读取，无需额外配置。

`npm install` 卡住时先查代理：

```bash
npm ping                     # 看通不通
npm config get proxy         # npm 自己有没有另配一套（会覆盖环境变量）
```

## npm 11 新行为：postinstall 默认被拦截

npm 11 出于供应链安全，默认不执行第三方包的 `postinstall`。

```bash
npm install-scripts ls              # 看哪些包在等放行
npm install-scripts approve 包名     # 确认可信后放行
```

本工程不需要放行任何脚本。

## 完成清单

```bash
node -v            # v24.21.0
which node         # ~/.nvm/... （不是 /mnt/c/...）
nvm use            # 读到 .nvmrc，切到 24
npm audit          # found 0 vulnerabilities
npm run check      # 全绿
```
