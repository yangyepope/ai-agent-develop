我建议我们的最终课程结构

为了避免再次出现“学着学着变成 RAG 课程”的问题，我建议以后严格按照这个比例：

模块占比



LLM 基础

10%

Agent 核心

35%

Tool Calling

15%

Memory

10%

Planning / Workflow

10%

RAG / Agentic RAG

8%

LangChain / LangGraph

7%

Multi-Agent

3%

Evaluation / Observability / Production

15%

其中 RAG 只占整个 Agent 学习路线的一部分。

最重要的一条学习原则

以后每一课都按照这个标准来：



理论
 ↓
架构
 ↓
核心原理
 ↓
从零实现
 ↓
完整独立项目
 ↓

 ↓
完整代码
 ↓
运行
 ↓
测试
 ↓
Debug
 ↓
实验
 ↓
工程化
 ↓
作业

而不是：



讲几个概念
 ↓
贴几十行代码
 ↓
结束

尤其是 Agent 部分，我们会坚持：

先自己手写 Agent → 再理解框架 → 最后使用 LangChain / LangGraph。

这样你以后即使不用 LangChain、LangGraph，自己也能写 Agent Engine。
