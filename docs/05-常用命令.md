# 05 · 常用命令

前提：终端里 `node -v` 能输出 `v24.21.0`。若不能，先 `source ~/.bashrc`。
所有命令都在 `/opt/AiAgentDevelop` 目录下执行。

## 启动 / 运行

| 命令                                     | 说明                          |
| ---------------------------------------- | ----------------------------- |
| `npm start lesson01-llm/01-hello.ts`     | 跑一次                        |
| `npm run dev lesson01-llm/01-hello.ts`   | 改动后自动重跑（Ctrl+C 退出） |
| `node --env-file-if-exists=.env 文件.ts` | 不经 npm 直接跑               |

> 加不加 `--` 都可以：`npm start -- 文件.ts` 和 `npm start 文件.ts` 等效。

## 装依赖

| 命令                    | 说明                                              |
| ----------------------- | ------------------------------------------------- |
| `npm install`           | 按 package.json 装全部（换机器 / 拉代码后第一步） |
| `npm install 包名`      | 装运行时依赖（代码里 import 的）                  |
| `npm install -D 包名`   | 装开发依赖（只在开发时用，如测试、lint 工具）     |
| `npm uninstall 包名`    | 卸载                                              |
| `npm install 包名@版本` | 装指定版本                                        |

装完如果提示 `install scripts not yet covered by allowScripts`：

```bash
npm install-scripts ls              # 看是哪个包
npm install-scripts approve 包名     # 确认可信后放行
```

## npm 与 npx 的区别

简单说：

- `npm`：用来安装和管理包
- `npx`：用来直接运行某个包里的命令

### 1) npm 是什么

`npm` 是 Node.js 的包管理工具，主要负责：

- 安装依赖
- 查看依赖列表
- 更新包
- 运行项目脚本

例如：

```bash
npm install lodash
npm install
npm run build
```

这些都是 `npm` 的常见用法。

### 2) npx 是什么

`npx` 是 `npm` 自带的一个命令，用来：

- 直接执行一个本地安装的命令
- 或临时下载并执行一个包，不用先安装到项目中

例如：

```bash
npx eslint .
npx ts-node src/index.ts
npx create-vite@latest my-app
```

它的特点是：

- 不一定要先装到项目中
- 适合临时使用命令行工具
- 会自动查找本地依赖，找不到则临时下载

### 3) 最核心的区别

可以把它们理解成：

- `npm` = 包管理器
- `npx` = 执行器

比如先安装一个工具：

```bash
npm install -D typescript
```

然后执行它：

```bash
npx tsc --version
```

这里的重点不是安装，而是运行这个命令。

### 4) 为什么要用 npx

因为有时候你不想把某个工具永久装进项目里，例如：

- 只想临时体验某个 CLI
- 想运行一次性脚本
- 不想污染 `package.json` 依赖

例如：

```bash
npx vitest
```

它会帮你运行对应命令，而不一定把依赖固定在项目中。

### 5) 一句话总结

> `npm` 是“安装和管理包”，`npx` 是“临时执行包里的命令”。

在实际开发中：

- 用 `npm`：安装依赖、管理项目依赖、运行脚本
- 用 `npx`：运行 CLI 工具、临时执行命令

## 检查

| 命令                 | 说明                                          |
| -------------------- | --------------------------------------------- |
| `npm run check`      | **格式 + lint + 类型 + 测试，提交前跑这一个** |
| `npm run typecheck`  | 只做类型检查（Node 运行时不检查类型，靠这个） |
| `npm run format`     | 格式化代码                                    |
| `npm run lint:fix`   | 自动修 lint 问题                              |
| `npm test`           | 跑测试                                        |
| `npm run test:watch` | 测试监听模式                                  |

## 查看 / 维护

| 命令                    | 说明                       |
| ----------------------- | -------------------------- |
| `npm ls --depth=0`      | 看直接依赖及版本           |
| `npm outdated`          | 看哪些依赖有新版           |
| `npm view 包名 version` | 查某个包的最新版本         |
| `npm audit`             | 安全审计                   |
| `npm run build`         | 产出 `dist/`（日常用不到） |

## 环境

| 命令                 | 说明                                       |
| -------------------- | ------------------------------------------ |
| `node -v` / `npm -v` | 看版本                                     |
| `which node`         | 必须指向 `~/.nvm/...`，不能是 `/mnt/c/...` |
| `nvm use`            | 按 `.nvmrc` 切到 Node 24                   |
| `nvm ls`             | 看装了哪些 Node 版本                       |
