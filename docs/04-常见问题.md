# 04 · 常见问题

命令速查见 [05 · 常用命令](./05-常用命令.md)。

## 环境

| 现象                                              | 原因 / 解决                                                                                                                |
| ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `node: command not found`（但 `npm -v` 有输出）   | `PATH` 里是 Windows 的 nvm4w。`source ~/.bashrc`，然后确认 `which node` 指向 `~/.nvm/...`                                  |
| `nvm: command not found`                          | nvm 是 shell 函数不是可执行文件，`which nvm` 查不到属正常。需 `source ~/.bashrc`                                           |
| 脚本里 `node` 找不到，交互终端里好用              | Debian 的 `~/.bashrc` 开头会让非交互 shell 直接 return。脚本里显式加载：`export NVM_DIR="$HOME/.nvm"; . "$NVM_DIR/nvm.sh"` |
| `npm install` 卡住                                | 先查代理：`npm ping`、`npm config get proxy`                                                                               |
| `install scripts not yet covered by allowScripts` | npm 11 默认拦 postinstall。`npm install-scripts ls` 看是哪个包，`approve 包名` 放行                                        |

## TypeScript 类型

| 报错                                                                         | 原因 / 解决                                                                             |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| `Cannot find module './x'`                                                   | 相对导入漏了 `.ts` 后缀。本工程**必须**带后缀                                           |
| `Object is possibly 'undefined'`                                             | `noUncheckedIndexedAccess` 在起作用（好事）。先判空，或直接用 `collectText(message)`    |
| `Property 'text' does not exist on type 'ContentBlock'`                      | `content` 是联合类型数组，必须先判 `block.type === 'text'`                              |
| `This syntax is not allowed when 'erasableSyntaxOnly' is enabled`            | 用了 `enum` / `namespace` / 构造器参数属性。替代写法见 [02](./02-TypeScript工程搭建.md) |
| `Object literal may only specify known properties, and 'xxx' does not exist` | SDK 版本太旧，还没这个字段                                                              |
| 改了类型却没报错                                                             | Node 运行 `.ts` **不做类型检查**。跑 `npm run typecheck`                                |

SDK 字段对不上时的排查（这个坑已经踩过一次，`output_config.effort` 需要新版）：

```bash
npm view @anthropic-ai/sdk version    # 最新版本
npm ls @anthropic-ai/sdk              # 实际装的版本
```

**不要靠记忆猜 SDK 字段名** —— 让 `npm run typecheck` 告诉你，编译器读的是实际安装的
`.d.ts`，永远比教程和记忆准。当前工程用 0.124.0。

## 运行时

| 报错                                     | 原因 / 解决                                                                            |
| ---------------------------------------- | -------------------------------------------------------------------------------------- |
| `缺少环境变量 ANTHROPIC_API_KEY`         | `cp .env.example .env` 后填 Key                                                        |
| `.env not found. Continuing without it.` | 提示而非错误。`cp .env.example .env` 即可消除                                          |
| `API Key 无效或已失效（401）`            | Key 是否复制完整、是否已轮换、账户有无余额、`.env` 里有无引号或空格                    |
| `连不上 API`                             | `curl -sI https://api.anthropic.com` 看通不通；`env \| grep -i proxy` 看代理变量在不在 |
| `触发限流（429）`                        | 请求太频繁，等一会儿。SDK 已自动重试 2 次                                              |
| `stop_reason` 是 `max_tokens`            | 回答被截断，调大 `max_tokens`                                                          |
| 400 报错提到 `temperature`               | 当前模型已移除该参数，改用 `output_config.effort`。见 [03](./03-第一课代码导读.md)     |
| 多轮对话模型"失忆"                       | 漏了 `history.push({ role: 'assistant', content: reply })`                             |

`.env` 写法（别加引号、等号旁别留空格）：

```bash
ANTHROPIC_API_KEY=sk-ant-api03-xxxx      # ✅
ANTHROPIC_API_KEY="sk-ant-api03-xxxx"    # ❌ 引号会成为值的一部分
ANTHROPIC_API_KEY = sk-ant-...           # ❌
```

`max_tokens` 参考值：分类/抽取 `256`；常规对话 `4096`~`16000`；
长文生成 `64000`（**必须配流式**，否则 HTTP 超时）。

## 工具链

| 现象                                   | 原因 / 解决                                                               |
| -------------------------------------- | ------------------------------------------------------------------------- |
| ESLint 报 `no-floating-promises`       | 忘了 `await`。故意不等就写 `void someAsyncFn()`                           |
| `npm run check` 里 `format:check` 失败 | 跑一次 `npm run format`                                                   |
| Prettier 和 ESLint 打架                | 本工程已分好工，不该冲突。遇到时先 `npm run format` 再 `npm run lint:fix` |
