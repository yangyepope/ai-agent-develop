# 职位描述：云安全 / DevSecOps 工程师

**标签**：AWS 云安全 · CI/CD 安全 · DevSecOps · 云网络架构 · 网络安全准入

## 岗位定位

负责公司云基础设施安全、网络安全、服务器安全、权限治理、代码安全、CI/CD 安全以及生产环境安全体系建设。

与运维团队形成职责分离，保障公司技术资产、业务数据和生产环境安全。

### 一、云平台安全（AWS 方向）

1. 负责 AWS 云环境安全建设和维护；
2. 设计 IAM 权限体系，实现最小权限原则；
3. 管理 VPC、安全组、网络访问策略；
4. 使用 CloudTrail、CloudWatch 等进行安全审计；
5. 推动云资源安全基线建设。

### 二、基础设施安全

负责服务器、网络、中间件安全建设：

1. Linux / Windows 服务器安全加固；
2. 防火墙策略设计与维护；
3. VPN、安全接入控制体系建设；
4. SSH 安全管理和访问审计；
5. 数据库安全管理；
6. Redis、MySQL、Kafka 等中间件安全配置；
7. 日志审计体系建设；
8. 服务器漏洞扫描和风险整改。

### 三、网络安全体系建设

1. 负责企业远程安全接入（VPN）体系设计与运维管理；
2. 建设 MFA、多因素认证和访问控制体系；
3. 负责 Zero Trust 访问策略建设；
4. 管理防火墙、安全组、IP 白名单等网络策略；
5. 建立内外网隔离和安全访问流程。

### 四、身份与权限管理

1. 负责 GitLab、AWS、服务器、VPN 等系统权限管理；
2. 建立 RBAC 角色权限模型；
3. 定期进行权限审计；
4. 管理员工入职、转岗、离职权限生命周期。

### 五、代码安全与 GitLab 安全

1. 负责 GitLab 权限体系设计；
2. 建立 Branch 保护、Merge 审批机制；
3. 推动代码安全扫描；
4. 防止代码泄露和敏感信息泄漏。

### 六、CI/CD 安全建设

1. 优化研发发布流程；
2. 建设安全自动化流水线；
3. 管理 GitLab Runner、Docker 镜像安全；
4. 推动开发、测试、生产环境隔离。

### 七、密钥和敏感信息管理

1. 负责支付 Key、API Token、数据库密码等敏感信息安全；
2. 推动 AWS Secrets Manager、KMS、Vault 等方案；
3. 避免密钥存储在代码和服务器配置文件中。

### 八、安全监控与事件响应

1. 建立安全日志体系；
2. 监控异常登录、权限提升、攻击行为；
3. 配合处理安全事件；
4. 推动漏洞扫描和风险整改。

## 任职要求

1. 3 年以上 DevOps、云安全、网络安全相关经验；
2. 熟悉 AWS 云服务及安全体系；
3. 熟悉 Linux 系统安全管理，了解 Windows 安全加固；
4. 熟悉网络安全基础，包括企业远程接入、防火墙、安全组、SSH；
5. 熟悉数据库和中间件安全，包括 MySQL、Redis、Kafka；
6. 熟悉 GitLab、CI/CD、Docker、Kubernetes；
7. 熟悉 IAM 权限设计和企业账号管理；
8. 了解 OWASP Top 10、漏洞管理、安全扫描。
